## ✦ Under the Hood

```text
portfolio/
├── api/
│   └── contact.ts          # Vercel serverless fn → Resend email
├── public/                 # favicon, résumé, sitemap, robots
├── src/
│   ├── components/         # ParticleScene, TiltCard, CursorGlow, IntroOverlay…
│   ├── sections/           # Hero, About, Skills, Projects, Experience, Contact
│   ├── pages/              # Home, ProjectDetail, 404
│   ├── data/               # profile, projects, skills, experience  ← edit content here
│   ├── hooks/              # useActiveSection (scroll-spy nav)
│   └── styles/
└── vercel.json             # security headers + SPA rewrites
```

> 💡 All the content is plain data in `src/data/`, so you can update projects or skills without touching a single component.

## ✦ Run It Locally

```bash
# 1. Clone
git clone https://github.com/GaneshMacharla/ganeshmacharlaportfolio.git
cd ganeshmacharlaportfolio

# 2. Install
npm install

# 3. Launch the dev server → http://localhost:5173
npm run dev
```

| Command | Does |
|---|---|
| `npm run dev` | Start the Vite dev server with HMR |
| `npm run build` | Production build into `dist/` |
| `npm run preview` | Serve the production build locally |
| `npm run typecheck` | Strict TypeScript check |

<details>
<summary><b>📬 Enabling the contact form</b></summary>
<br/>

The form posts to `/api/contact`, which runs as a Vercel function. Set these in Vercel (or `.env.local` with `vercel dev`):

| Variable | Required | Purpose |
|---|:-:|---|
| `RESEND_API_KEY` | ✅ | API key from [resend.com](https://resend.com) |
| `CONTACT_FROM_EMAIL` | ➖ | Sender, defaults to `onboarding@resend.dev` |
| `CONTACT_TO_EMAIL` | ➖ | Where messages land |

</details>
